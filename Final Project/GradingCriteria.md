# Tier Rankings

| Score | Tier | Recognition |
|-------:|------|-------------|
| **95–100** | **S** | Hall of Fame |
| **90–94** | **A** | Platinum |
| **80–89** | **B** | Gold |
| **70–79** | **C** | Silver |
| **60–69** | **D** | Bronze |
| **Below 60** | **F** | Incomplete |

### Tier Descriptions

| Tier | Description |
|------|-------------|
| **S** | Outstanding quality. Highly polished, technically sound, and demonstrates exceptional craftsmanship. |
| **A** | Excellent execution with only minor areas for improvement. |
| **B** | Solid project that meets expectations and is enjoyable to play. |
| **C** | Functional and complete but lacks polish or has noticeable issues. |
| **D** | Significant improvements are needed, though the project shows effort and potential. |
| **F** | Incomplete, unstable, or missing major project requirements. |

---

# Completion Rating

> Completion is evaluated separately from the overall score to recognize how complete the final project is.

| Rating | Description |
|--------|-------------|
| ★★★★★ | Fully complete, polished, and all required features are implemented. |
| ★★★★☆ | Complete with only minor missing features or polish. |
| ★★★☆☆ | Mostly complete, but several features remain unfinished. |
| ★★☆☆☆ | Playable but noticeably incomplete. |
| ★☆☆☆☆ | Prototype or largely unfinished project. |
